Translate the chosen low-fi sketch directions into mid-fidelity wireframes in Figma, applying Toast's design system. Annotate key design decisions so the case study can reference the reasoning behind each choice.

- Date range / perishable item flow

All wireframes should use Toast's visual language (typography, spacing, color tokens) to the extent possible.
